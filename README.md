# LLM-CodeReviewer
Python tool that leverages **OpenAI GPT-4** to review inputted python snippets. 

## Installation   
1. Create a API key at https://platform.openai.com/api-keys
2. Clone the repo
<pre> <code> git clone https://github.com/Felixly1/LLM-CodeReviewer.git  </code> </pre>
3. Pip install the OpenAI SDK
<pre> <code> pip install openai  </code> </pre>
4. Export your API key as a environment variable in your terminal
<pre> <code> setx OPENAI_API_KEY "your_api_key_here"  </code> </pre>
